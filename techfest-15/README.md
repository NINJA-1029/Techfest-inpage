# Techfest — 15 landing-page concepts

Fifteen standalone, responsive concept pages for Techfest, IIT Bombay: a CSS-only spatial experience, a parallax-scroll experience, and a no-3D graphic landing page across five distinct visual directions.

## Open locally

Open `index.html` directly in a browser. Select one of the 15 cards; use the footer link on each concept to return. No build step or package install is required. Google Fonts are optional; system fallbacks are included.

## Notes

- Each concept is a separate HTML file and can be hosted as static pages.
- The spatial route uses CSS perspective, gradients and transform layers; it contains no external 3D model assets or WebGL.
- The parallax route moves background, central and foreground elements at different scroll speeds. Reduced-motion preferences disable scripted motion.
- The no-3D route is built with flat type, geometry, and color blocks.
- Content is an independent concept study informed by public Techfest pages. This is not an official Techfest site. Live programme and registration details link to [techfest.org](https://techfest.org).
- Current official pages checked: [Techfest home](https://techfest.org), [competitions](https://techfest.org/competitions/zero-code), [College Ambassador programme](https://ca.techfest.org/).
